# `data/` — local data store

Everything under `data/` is generated by the pipeline (`scripts/run_pipeline.sh`
or the `pipeline.*` modules directly). The synthetic-fixture outputs are
committed so the app is runnable out of the box; regenerate them any time with
`bash scripts/run_pipeline.sh`.

```
data/
├── raw/                          # source dumps (your local DataSet lives here; gitignored)
│
├── processed/                    # EXACTLY ONE self-contained file per plot (§5) — what the API serves
│   ├── plot1_gdp_ntl_residual.parquet   # View 1 — GDP–NTL residual (country-year)
│   ├── plot2_conflict_type.parquet     # View 2 — Light loss due to conflict
│   ├── plot3_shock_recovery.parquet     # View 3 — luminosity recovery based on development factors
│   ├── plot4_spillover.parquet          # View 4 — epicenter→neighbor edges
│   └── plot5_trade_sankey.parquet              # View 5 — trade analysis
│
└── geo/                          # reference data (not per-plot)
    ├── countries.json            # iso3, name, region, has_conflict, conflict_onset
    ├── adjacency.json            # {iso3: [neighbor_iso3, ...]}
    └── countries.geojson         # boundary polygons, keyed by iso3
```

`compute_derived` distills the `interim/` panels into the five `processed/`
plot files; the backend reads only those five (plus `geo/`).

## Regenerate everything

```bash
bash scripts/run_pipeline.sh
```
